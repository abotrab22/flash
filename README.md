# حاسبة الأقساط

تطبيق ويب عربي متوافق مع الهواتف لتحويل السعر النقدي بالدينار العراقي إلى سعر أقساط على ١٠ أشهر، مع تقريب الإجمالي لأقرب ١٠٬٠٠٠ دينار.

## الاستخدام

افتح `index.html` في المتصفح، ثم:

1. أدخل السعر النقدي بالدينار العراقي (تُقبل الأرقام العربية والإنجليزية).
2. يُضاف ٢٠٪ إلى السعر النقدي، ثم يُقرّب الإجمالي لأقرب ١٠٬٠٠٠ دينار عراقي.
3. تظهر قيمة الإضافة الناتجة عن التقريب والقسط الشهري التقريبي مباشرة.

يُقسّم الإجمالي المقرب على ١٠ أقساط متساوية. لا يحتاج التطبيق إلى تثبيت حزم أو اتصال بخدمة خارجية. ويمكن نشره على GitHub Pages باستخدام سير العمل الموجود في `.github/workflows/pages.yml`.
