# حاسبة الأقساط

تطبيق ويب عربي متوافق مع الهواتف لتحويل السعر النقدي إلى سعر أقساط بإضافة ٢٠٪.

## الاستخدام

افتح `index.html` في المتصفح، ثم:

1. أدخل السعر النقدي (تُقبل الأرقام العربية والإنجليزية).
2. حدّد عدد الأقساط من شهر إلى ٦٠ شهراً.
3. تظهر قيمة الزيادة، والسعر الإجمالي، والقسط الشهري التقريبي مباشرة.

لا يحتاج التطبيق إلى تثبيت حزم أو اتصال بخدمة خارجية. ويمكن نشره على GitHub Pages باستخدام سير العمل الموجود في `.github/workflows/pages.yml`.
