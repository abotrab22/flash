# حاسبة الأقساط

تطبيق ويب عربي متوافق مع الهواتف لتحويل السعر النقدي بالدينار العراقي إلى سعر أقساط على ١٠ أشهر، مع إضافة نسبة تختلف حسب نوع الجهاز وتقريب الإجمالي لأقرب ٥٬٠٠٠ دينار.

## الاستخدام

افتح `index.html` في المتصفح، ثم:

1. اختر نوع الجهاز: موبايل لإضافة ٣٠٪، أو باقي الأجهزة لإضافة ٢٠٪.
2. أدخل السعر النقدي بالدينار العراقي (تُقبل الأرقام العربية والإنجليزية).
3. يُقرّب الإجمالي لأقرب ٥٬٠٠٠ دينار عراقي، وتظهر قيمة الإضافة الناتجة عن التقريب والقسط الشهري التقريبي مباشرة.

يُقسّم الإجمالي المقرب على ١٠ أقساط متساوية. لا يحتاج التطبيق إلى تثبيت حزم أو اتصال بخدمة خارجية. ويمكن نشره على GitHub Pages باستخدام سير العمل الموجود في `.github/workflows/pages.yml`.
