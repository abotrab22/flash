# حاسبة الأقساط

تطبيق ويب عربي متوافق مع الهواتف لتحويل السعر النقدي إلى سعر أقساط على ١٠ أشهر.

## الاستخدام

افتح `index.html` في المتصفح، ثم:

1. أدخل السعر النقدي (تُقبل الأرقام العربية والإنجليزية).
2. تظهر قيمة الإضافة، والسعر الإجمالي، والقسط الشهري التقريبي مباشرة.

يُحتسب سعر الأقساط تلقائياً، ويُقسّم على ١٠ أقساط متساوية. لا يحتاج التطبيق إلى تثبيت حزم أو اتصال بخدمة خارجية. ويمكن نشره على GitHub Pages باستخدام سير العمل الموجود في `.github/workflows/pages.yml`.
